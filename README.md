# USA Real Estate Dashboard (Power BI)

An interactive Power BI report on US property listings: prices, property attributes and location.

**File:** [`USA REAL ESTATE DATA SET.pbix`](USA%20REAL%20ESTATE%20DATA%20SET.pbix). Open it in Power BI Desktop (free) to use the slicers and drill-downs.

**Tools:** Power BI Desktop (Power Query, DAX)
